# Roadmap

Roadmap items describe intent, not shipped capability or a delivery promise.

## Alpha: inspect and deploy

- Publish reproducible source, synthetic workflow evidence, Docker deployment, provisional adopter-owned Railway instructions, and public review routes.
- Document every material claim, boundary, threat, and unresolved production dependency.
- Complete one clean installation outside the development machine.

## Design-partner release

- Improve onboarding from observed installation failures.
- Add portable deployment readiness, organization milestones, and email providers.
- Validate the adopter-owned Railway topology using only adopter-held credentials.

## Controlled case release

- Complete one consented permission from authority evidence through decision, publication evidence, external payment evidence, beneficiary payouts, and signed reconciliation.
- Publish only the redacted evidence approved by every named participant.
- Record accepted, rejected, and unresolved reviewer feedback.

## Stable-release gate

A stable release requires repeated independent deployments, upgrade testing, a qualified real-pilot verification, security review, restore testing, legal-policy review, and no unresolved critical receipt or authority defect.
